# Gift Registry

**Video Presentation:** (https://youtu.be/vF1fR6UDXWg)

## About the Project

This project is a Python gift registry program. It allows a user to add gifts (and their price) to a registry, view their gifts, mark gifts as purchased, and remove gifts from the registry. 

## Features

- Add a gift and its price
- View all gifts in the registry
- See whether a gift has been purchased
- Mark a gift as purchased
- Remove a gift
- Exit the program

## Course Concepts Used

This project uses concepts from Chapters 1-8, including:

- Variables and simple data types
- Lists and dictionaries
- If, elif, and else statements
- For loops and while loops
- User input
- Functions

## How to Run the Program

1. Download the project from GitHub.
2. Open the project in VS Code.
3. Run the gift_registry.py file using Python.
4. Choose an option from the menu (1–5).
5. Follow the instructions on the screen.
6. Enter 5 to exit the program.
